# 画面デザインの方針

すべての画面（家計簿・カレンダー・買い物リスト・スマートホーム）を、[unslop](../.claude/skills/unslop/SKILL.md)（Damir Sokolovsky, CC BY 4.0）の手順で作り直しました。

## 方向性

- **プロダクト**: 夫婦2人で、家計の精算・休日・買い物・家電をまとめて回すための家族アプリ
- **性格**: 落ち着いている、正確、少し温かい
- **世界観**: 夜の台所のテーブルに広げた家計簿のノートとレシート
- **見せ場**: 合計カードを1枚の「精算レシート」として描く。内訳グラフは色ごとにカテゴリーを表す
- **シグネチャー**: レシートの点線の区切りと、等幅の数字

## 色

| 役割 | 値 | Tailwind |
|---|---|---|
| 一番奥の面（フッター・出力欄） | #0f0f10 | `bg-graphite-deep` |
| ページの背景 | #141415 | `bg-graphite-page` |
| カード | #19191b | `bg-graphite-card` |
| 一段上の面（入力欄・選択中） | #232325 | `bg-graphite-raised` |
| 枠線 | 文字色の6〜10% | `ring-white/[0.08]` |
| 文字 | 主・副・控えめの3段 | `text-zinc-100` / `text-zinc-300` / `text-zinc-500` |
| 差し色 | 琥珀色 | `amber-400`（面）/ `amber-300`（文字） |

- **差し色は、選択中の状態と、大事な数字だけに使います。** 精算額、クイック入力中のボタン、推移グラフの今月、計算機の「＝」などです。
- **主ボタンは白に近いグレーです。** `bg-zinc-100 text-zinc-900`。画面ごとに1つまでにし、ほかは一段上の面のボタンにします。
- **意味のある色は控えめに使います。** 予算バーは、余裕がある間はグレー、8割を超えたら琥珀色、超過したら赤です。
- **人物の色は小さなドットだけです。** 夫は空色、妻はピンクで、面や文字には使いません。
- **グラデーション・光・色付きの影は使いません。** 例外はレシートの紙の、同じ色の中のわずかな明暗だけです。

## 文字

- **本文は Noto Sans JP、数字は IBM Plex Mono です。** 金額・日付・件数は `font-mono tabular-nums` で桁をそろえます。
- **太さは 400 と 500 だけです。** 見出しの強さは、太さではなく大きさと色で出します。
- **文言に感嘆符は使いません。** 短いラベルやボタンの末尾に句点も付けません。

## レシート

合計カードの表面は `.receipt-paper`（css/app.css）で描きます。

- 紙は `#f5f1e7` から `#efe9dc` への、同じ色の中のわずかな明暗です。
- 上下の縁は、マスクで半円に欠いてミシン目にしています。
- 区切りは `.receipt-rule` の点線です。
- 精算額だけ、紙の上で読める濃い琥珀色 `text-paper-accent` を使います。

## アイコン

- **画面の中に絵文字は使いません。** アイコンは `js/icons.js` の線のアイコン（lucide）だけです。
- Discord や PayPay に送るメッセージ本文の絵文字は、画面ではないのでそのままです。

## 画面ごとのメモ

### カレンダー

- 休日編集で選んだ日は `bg-amber-400 text-zinc-900` です。今日の枠も琥珀色です。
- セルの中の予定（Googleカレンダー）は空色、メモ・タスクはグレーです。人物はドットで示します。
- セルの文字は最小 10px です。スマホでは予定の時刻を省き、タイトルだけを出します（`_gcalCellLabel`）。
- 7列は `repeat(7, minmax(0, 1fr))` で同じ幅にそろえます。中身の長さで列幅が変わらないようにするためです。

### 買い物リスト

- カテゴリーは見出しの文字だけで、絵文字は付けません。
- 優先度は小さな文字だけです。急ぎは `text-rose-300`、後では `text-zinc-500` です。
- チェックした項目は琥珀色の丸に濃い色のチェックです。

### スマートホーム

- 家電の種類は線のアイコンで示します（エアコンは snowflake、照明は lightbulb など）。
- エアコンのモード・風量の選択中は琥珀色です。

## 動き

- 色と面の切り替えだけで、`transition-colors` を使います。押したときは少しだけ縮めます。
- ずっと動き続けるものは、読み取り中のくるくるだけです。
