# レシート読み取り（Claude API）

スマホで撮ったレシートを Claude に読み取らせ、店名・日付・金額を家計簿に追加する機能です。
「その他」→「レシート読み取り」、またはカテゴリー追加シートの「レシートを撮って追加」から使います。

---

## 1. 仕組み

```
アプリ（ブラウザ）
  │ 写真を縮小（長辺2576px以内・画像トークン4784以内）してJPEGのbase64に
  │ POST /receipt（X-App-Key: アプリキー）
  ▼
gcal-sync Worker（Cloudflare）
  │ アプリキーの確認・1日の回数上限・画像の検証
  │ ANTHROPIC_API_KEY（Workerのシークレット）を付けて Messages API を呼ぶ
  ▼
Claude API（claude-opus-5-5, effort: low, 構造化出力）
  └ 店名・日付・合計・支払方法・品目・カテゴリー候補をJSONで返す
```

- **APIキーはWorkerにだけ置きます。** アプリ（GitHub Pages）には一切含めません。
- **Workerはカレンダー連携と同じ gcal-sync を使います。** アプリキーも同じなので、端末ごとの設定は増えません。
- **読み取り結果は必ず確認画面で見直してから追加します。** 自動では追加しません。
- 追加先は**表示中の月**です。レシートの日付が別の月なら、確認画面に注意が出ます。
- **クレジットカード払いのレシートには、二重計上の注意が出ます。** カード払いは明細の取込で入るためです。

## 2. セットアップ（一度だけ）

### 手順1: Claude Console で APIキーを作る

1. [Claude Console](https://platform.claude.com/) にログインし、API Keys からキーを作成します。
2. 表示されたキーはこの後の手順2で Cloudflare に貼り付けます。**チャットやリポジトリには貼らないでください。**

Max 5x プランの特典クレジット（毎月 $100）は、プランに紐づけた Console の組織に毎月届きます。
支払い方法を登録していなければ、クレジットを使い切った時点で API が止まるだけで、請求は発生しません。
詳しくは [API credits for Max and Team plans](https://platform.claude.com/docs/en/about-claude/api-credits-for-subscribers) を参照してください。

> 他の用途にもクレジットを使う場合は、レシート用に Workspace を分けて月の上限（Spend limits）を設定すると、使いすぎを防げます。
> Settings > Workspaces で Workspace を選ぶと設定できます。デフォルトの Workspace には上限を設定できません。

### 手順2: Cloudflare の Worker にシークレットを追加

1. Cloudflare ダッシュボード → Workers & Pages → **gcal-sync** を開きます。
2. 設定（Settings）→ 変数とシークレット（Variables and Secrets）→ 追加（Add）。
3. 種類は **シークレット（Secret）**、名前は `ANTHROPIC_API_KEY`、値に手順1のキーを貼り付けて保存（Deploy）します。

任意で、次の**変数**（テキスト）も追加できます。

| 名前 | 既定値 | 内容 |
|---|---|---|
| `RECEIPT_DAILY_LIMIT` | `50` | 1日に読み取れる回数の上限（日本時間で日付が変わるとリセット） |
| `RECEIPT_MODEL` | `claude-opus-5-5` | 読み取りに使うモデル。料金を抑えたい場合は `claude-haiku-5-5` |

### 手順3: Worker のコードを更新

1. gcal-sync の「コードを編集（Edit code）」を開きます。
2. リポジトリの `worker/gcal-sync/worker.js` の内容に丸ごと置き換えて、デプロイします。

カレンダー同期の処理は変わっていないので、置き換えても連携はそのまま続きます。

### 手順4: 動作確認

1. アプリで「その他」→「レシート読み取り」→「撮影する」でレシートを撮ります。
2. 確認画面に店名・日付・金額が出れば完了です。
3. その端末でまだカレンダー連携をしていない場合は、最初にアプリキーの入力を求められます。

## 3. 料金の目安

1枚あたりの目安です（Claude Opus 5.5 の料金: 入力 $4 / 出力 $20、100万トークンあたり）。

| 内訳 | トークン | 料金 |
|---|---|---|
| 画像 | 最大 約4,800 | 約 $0.019 |
| 指示文・カテゴリー候補 | 約700 | 約 $0.003 |
| 出力（読み取り結果のJSONと思考） | 約400〜800 | 約 $0.008〜0.016 |
| **合計** | | **約 $0.03〜0.04（5〜6円ほど）** |

毎月 $100 のクレジットなら、およそ2,500枚以上読み取れます。
1日の上限が既定の50回なら、上限まで毎日使っても1か月 $60 前後に収まります。
実際の利用額は Console の [Cost](https://platform.claude.com/cost) ページで確認できます。

## 4. 困ったとき

| 表示されるメッセージ | 原因と対処 |
|---|---|
| レシート読み取りの設定がまだです | Worker に `ANTHROPIC_API_KEY` がありません。手順2を行ってください |
| アプリキーが正しくありません | 端末のアプリキーが Worker の `APP_KEY` と違います。もう一度撮ると入力し直せます |
| Claude APIのキーが正しくありません | `ANTHROPIC_API_KEY` の値が誤っているか、キーが無効化されています |
| 今日の読み取り回数の上限に達しました | `RECEIPT_DAILY_LIMIT` の回数に達しました。翌日に戻ります |
| 今月のAPIクレジット（または利用上限）を使い切りました | 次の更新日までお待ちいただくか、Console の Billing を確認してください |
| レシートが見つかりませんでした | レシート全体が写るように、明るい場所で撮り直してください |

## 5. プライバシー

- 写真はアプリで縮小したうえで Claude API に送られます。アプリと Worker には保存しません。
- Anthropic の説明では、API に送った画像はリクエストの処理後に削除され、モデルの学習には使われません（[Vision](https://platform.claude.com/docs/en/build-with-claude/vision) の FAQ）。

## 6. 実装メモ

- **Worker は SDK ではなく fetch で API を呼びます。** ダッシュボードにファイルを貼り付けて配置しており（ビルド工程なし）、npm パッケージを読み込めないためです。
- **画像の base64 は JSON に通さず、文字列のまま差し込みます。** 数MBの文字列の JSON 解析・生成を避け、無料プランの CPU 時間の上限に収めるためです。文字種は Worker で検証しています。
- **構造化出力のスキーマは固定です。** スキーマが毎回同じだと、API 側でコンパイル結果が再利用されます。カテゴリー候補はユーザーメッセージで渡します。
- **プロンプトキャッシュは使いません。** 読み取りは間隔が空くため、5分のキャッシュはほぼ書き込みだけになり、かえって割高になるためです。
- **安全分類器が誤って断った場合に備えて、`fallbacks: "default"` を有効にしています。** API が推奨モデルで自動的にやり直します。
