# 家族カードの買い物

家族カードで払った買い物のうち、**共有の買い物**をその場で記録しておく機能です。
カード明細が届いたときに、この記録と家族カードの行を照らし合わせ、記録のない行を個人の利用として分けるために使います。

「その他」→「家族カードの買い物」から開きます。

---

## 1. 全体の流れ

| 段階 | 内容 | 状態 |
|---|---|---|
| 1 | 共有の買い物を、使ったその場で記録する | **実装済み**（この文書） |
| 2 | 妻のスマホでログインできるようにする（`firestore.rules` にUIDを追加） | 未対応 |
| 3 | 明細の取込で、家族カードの行と記録を照らし合わせる。記録のない行を個人の利用として分ける | 未対応（明細の実物を見てから作る） |

## 2. 記録のしかた

- **金額を入れて記録する。** 使った日・金額・店名・カテゴリー・メモを入れて「記録する」。必須は使った日と金額だけです。
- **レシートを撮って記録する。** 「レシートを撮って記録」から、レシート読み取りを開きます。
  レシート読み取りを「その他」から開いた場合も、確認画面の「記録先」を「家族カードの買い物」にすれば同じです。
- 一覧の行を押すと、その記録を直せます。×で削除します。

**記録は、家計簿の合計にはまだ入りません。** カード払いは明細の取込で家計簿に入るため、ここで入れると二重になるからです。

## 3. データの形

保存先は Firestore の `budgetData/familyCardPurchases` です。既存のルール（`budgetData/{document}`）の範囲なので、ルールの変更は要りません。

```
{
  items: {
    "<記録ID>": {
      id: "<記録ID>",
      date: "2026-11-08",      // 使った日（YYYY-MM-DD）
      store: "イオン",          // 店名（空のこともある）
      amount: 3280,            // 金額（円・整数）
      category: "食費",         // カテゴリー名（未定なら空）
      memo: "",
      source: "receipt",       // "receipt"（レシート）か "manual"（手入力）
      createdAt: "2026-11-08T03:12:45.000Z"
    }
  }
}
```

- **1件ずつ `merge` で書きます。** 夫婦が別々の端末から同時に記録しても、互いの記録を消しません。
  全件をまとめて上書きする形にすると、片方の記録が消えることがあります。
- **空の項目も必ず持たせます。** `merge` は書いた項目だけを上書きするため、項目を省くと、直す前の値が残ってしまいます。
- 削除は `deleteField()` で、その記録だけを消します。

## 4. 照らし合わせに使う項目（段階3の予定）

- **金額**: 明細の金額と一致するものを探します。
- **使った日**: 明細の利用日との前後のずれを許して探します。
- **カテゴリー**: 一致した行を家計簿に入れるときの分類に使います。

## 5. 実装メモ

- 画面と処理: `js/family-card.js`（`FamilyCardManager`）
- レシート読み取りとの接続: `js/receipt.js` の `target`（`'budget'` か `'family'`）
- テスト: `tests/family-card.test.mjs`
